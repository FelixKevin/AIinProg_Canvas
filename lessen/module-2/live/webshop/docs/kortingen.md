# Kortingen

Afspraken met de klant, versie november.

## Studentenkorting

- Studenten krijgen 15% korting op hun bestelling.
- De korting geldt enkel voor bestellingen vanaf 2000 eurocent (20 euro).
- De korting wordt afgerond naar beneden op een hele cent.
- Een klant is student als `customer.isStudent` gelijk is aan `true`.

## Algemeen

- Alle bedragen zijn gehele getallen in eurocent.
- Kortingen worden nooit gecombineerd.

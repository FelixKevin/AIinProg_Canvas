Oefeningen module 3

In deze opdracht maak je de oefeningen van module 3: Code genereren. Je maakt ze tijdens de les. Volg je de les niet in het lokaal? Dan maak je ze zelfstandig: op de pagina met de oefeningen staat onder Zo doorloop je deze les in welke volgorde je leest en werkt. Je werkt in een invulbestand en levert dat bestand hier in.

Zo ga je te werk

  1. Download het invulbestand: oefeningen-module-3-invulbestand.docx.
  2. Download de startbestanden voor oefening M1 tot en met M4 en pak de zip uit: startbestanden-module-3.zip. Je kan ze ook zelf aanmaken: de code staat in de opgave.
  3. Open de pagina Oefeningen module 3. Daar staan de volledige opgaven. Lees eerst het deel Voor je begint: daar staat welke map je opent, hoe je je scène in je browser bekijkt en hoe je een versie van je map bewaart.
  4. Typ je antwoorden in de lichtblauwe vakken van het invulbestand. Verwijder geen titels of vragen.
  5. Bewaar je bestand als .docx of .pdf met de naam module3_voornaam_achternaam.
  6. Lever het bestand in via deze opdracht.

Wat maak je?

  • Kernreeks (verplicht): M1 tot en met M4 en E1, in die volgorde.
  • Extra-reeks (optioneel): X1 tot en met X15. Wil je meer oefenen, maak er dan zoveel als je wil.

In M1 tot en met M4 bouw je een eigen 3D-scène met three.js, in één map. Je hoeft three.js niet te kennen.

Wat lever je in?

Je levert alleen het invulbestand in. Screenshots en code plak je in het invulbestand, op de plaats waar de oefening erom vraagt. Je mappen (scene, scene-v1, …) lever je niet in. Bewaar ze wel bij je portfolio.

Wat heb je nodig?

  • Een agent harness, zoals GitHub Copilot in Visual Studio Code, voor elke oefening waarin je een prompt verstuurt. Is dat nog niet in orde? Volg dan de startgids: startgids-vscode-copilot.pdf.
  • Een browser, zoals Chrome, Edge of Firefox, en een internetverbinding.
  • Node.js, voor oefening M4. Op de pagina met de oefeningen staat hoe je controleert of het geïnstalleerd is.

Elke prompt kost AI credits, en je tegoed per maand is beperkt. Daarom zegt elke oefening hoeveel prompts je hoogstens stuurt. Hou je daaraan. Noteer bij elke oefening waarin je een prompt verstuurt welke agent harness en welk model je gebruikte.

Je prompts, je antwoorden en je conclusies schrijf je zelf. Je moet alles wat je inlevert kunnen uitleggen.

Waarom lever je dit in?

Je ingevulde oefeningen zijn een deel van je portfolio, en ze tellen mee voor je eindcijfer. In de examenperiode van januari verdedig je je portfolio mondeling. Werk dus zorgvuldig: je docent kan je vragen om alles wat je hier schrijft uit te leggen.

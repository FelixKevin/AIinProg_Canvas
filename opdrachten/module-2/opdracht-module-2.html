Oefeningen module 2

In deze opdracht maak je de oefeningen van module 2: Prompts en context. Een deel maak je tijdens de les. De rest werk je thuis af. Je kan alle oefeningen zelfstandig maken, ook als je de les niet in het lokaal volgt. Je werkt in een invulbestand en levert dat bestand hier in.

Zo ga je te werk

  1. Download het invulbestand: oefeningen-module-2-invulbestand.docx.
  2. Download de startbestanden voor oefening M2 en M3 en pak de zip uit: startbestanden-module-2.zip. Je kan ze ook zelf aanmaken: de code staat in de opgave.
  3. Open de pagina Oefeningen module 2. Daar staan de volledige opgaven. Lees eerst het deel Voor je begint: daar staat welke map je opent en hoe je je code test.
  4. Typ je antwoorden in de lichtblauwe vakken van het invulbestand. Verwijder geen titels of vragen.
  5. Bewaar je bestand als .docx of .pdf met de naam module2_voornaam_achternaam.
  6. Lever het bestand in via deze opdracht.

Wat maak je?

  • Kernreeks (verplicht): E1 tot en met E4, M1 tot en met M5, H1, H2 en @1.
  • Extra-reeks (optioneel): X1 tot en met X14. Wil je meer oefenen, maak er dan zoveel als je wil.

Voor oefening @1 hou je één week lang een logboek bij. Begin er dus op tijd aan.

Wat heb je nodig?

  • Een agent harness, zoals GitHub Copilot in Visual Studio Code, voor elke oefening waarin je een prompt verstuurt. Is dat nog niet in orde? Volg dan de startgids: startgids-vscode-copilot.pdf.
  • Node.js, om JavaScript uit te voeren. Op de pagina met de oefeningen staat hoe je controleert of het geïnstalleerd is.

Start voor elke nieuwe prompt een nieuw gesprek, tenzij de oefening iets anders zegt. Noteer bij elke oefening waarin je een prompt verstuurt welke agent harness en welk model je gebruikte.

Je prompts, je antwoorden en je conclusies schrijf je zelf. Je moet alles wat je inlevert kunnen uitleggen.

Waarom lever je dit in?

Je ingevulde oefeningen zijn een deel van je portfolio, en ze tellen mee voor je eindcijfer. In de examenperiode van januari verdedig je je portfolio mondeling. Werk dus zorgvuldig: je docent kan je vragen om alles wat je hier schrijft uit te leggen.

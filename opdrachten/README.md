# Opdrachten

Material for Canvas assignments, one folder per module. Nothing here is read by `sync.js`; you upload or paste it into Canvas yourself.

| File | Use |
|---|---|
| `module-N/oefeningen-module-N-invulbestand.docx` | Fill-in file for the exercises of module N. Upload it to the course Files and link it from the assignment. |
| `module-N/opdracht-module-N.html` | Description for the Canvas assignment. Paste it in the HTML editor of the assignment and replace the `[…]` placeholders. |

Suggested assignment settings: submission type **Online → File upload**, allowed extensions `docx,pdf`.

When the exercises in `content/module-N-oefeningen.md` change, update the fill-in file too.

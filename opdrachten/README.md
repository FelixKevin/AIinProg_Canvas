# Opdrachten

Material for Canvas assignments, one folder per module, plus a setup guide for students. Nothing here is read by `sync.js`; you upload or paste it into Canvas yourself.

| File | Use |
|---|---|
| `module-N/oefeningen-module-N-invulbestand.docx` | Fill-in file for the exercises of module N. Upload it to the course Files and link it from the assignment. |
| `module-N/opdracht-module-N.html` | Description for the Canvas assignment. Paste it in the HTML editor of the assignment and replace the `[…]` placeholders. |
| `module-N/starter/` | Starter code for exercises that need files, one folder per exercise. An exercise that tests two prompts has two identical folders, `-a` and `-b`, so students never have to undo a change. The same code is shown in the exercise text. |
| `module-N/startbestanden-module-N.zip` | The `starter/` folder as a zip. Upload it to the course Files and link it from the assignment. Rebuild it when `starter/` changes. |
| `startgids/startgids-vscode-copilot.pdf` | Setup guide for students: Visual Studio Code with GitHub Copilot (sign-in, chat, open a folder, usage, models, permissions, instruction files, other agent harnesses). Upload it to the course Files. |
| `startgids/startgids-vscode-copilot.html` | Source of the guide. The window drawings are sketches made with HTML and CSS, not screenshots. Rebuild the PDF after changing it: open the file in Chrome and print to PDF (A4, background graphics on). |

The guide describes the user interface of VS Code and the Copilot plans, and both change often. Check it against the VS Code and GitHub Copilot documentation at the start of each semester, and update the date at the bottom.

Suggested assignment settings: submission type **Online → File upload**, allowed extensions `docx,pdf`.

When the exercises in `content/module-N-oefeningen.md` change, update the fill-in file too.

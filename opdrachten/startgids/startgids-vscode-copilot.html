Startgids: VS Code en GitHub Copilot

In deze cursus werk je met GitHub Copilot in Visual Studio Code (VS Code). GitHub Copilot is de agent harness: de software rond het model, die je bestanden leest en aanpast. Met deze gids zet je alles één keer klaar. Reken op 15 minuten. Op het einde staat een checklist.

De schermen in deze gids zijn schetsen. VS Code verandert vaak, dus bij jou kan een knop op een andere plaats staan. De namen van knoppen staan in het Engels, zoals in VS Code zelf.

1Wat heb je nodig?

  • Visual Studio Code, de laatste versie. Download het op code.visualstudio.com. Heb je het al? Kies Help > Check for Updates (op Mac: Code > Check for Updates).
  • Een GitHub-account. Maak er gratis een op github.com.
  • GitHub Copilot voor studenten. Dat is gratis. Het plan heet Copilot Student. Je vraagt het één keer aan:
  1. Ga naar github.com/settings/education/benefits en klik Start an application.
  2. Vul het formulier in. Gebruik het e-mailadres van de school, of een bewijs dat je student bent (bijvoorbeeld je studentenkaart).
  3. Wacht op de goedkeuring. Dat kan enkele dagen duren.
  4. Kijk daarna op github.com/settings/copilot welk plan actief is.

Is je aanvraag nog niet goedgekeurd? Dan krijg je Copilot Free. Daarmee kan je al starten, maar met meer beperkingen.

2Meld je aan in VS Code

  1. Open VS Code. Onderaan rechts, in de Status Bar, staat het Copilot-icoon (4 in de schets bij stap 3).
  2. Ga er met je muis op staan en kies Use AI Features of Sign in to use Copilot.
  3. Meld je aan met het GitHub-account waarop je studentenplan staat.

Lukt het niet? Klik links onderaan op Accounts en kies Sign in with GitHub to use GitHub Copilot.

3Open de chat

In de chat typ je je prompts. Zo open je ze:

  • Klik bovenaan in de titelbalk op Chat en kies Open Chat (1).
  • Of druk Ctrl + Alt + I (op Mac: Ctrl + Cmd + I).

De chat opent rechts in je venster (3). Met New Chat (+) begin je een nieuw gesprek. Doe dat voor elke nieuwe taak: zo blijft de context klein en verbruik je minder.

4Open altijd eerst een map

Kies File > Open Folder… en open de map van je taak of project (2). Doe dat vóór je een prompt typt.

  • Waarom? De map die je opent is de werkmap (workspace) van de agent harness. Daar zoekt, leest en wijzigt de agent bestanden. Zonder map weet hij niet waar je project staat.
  • Eén taak, één map. Open de map van die taak. Open niet je hele map Documenten of je hele schijf: dan ziet de agent te veel, en kan hij ook te veel aanpassen.
  • Vraagt VS Code Do you trust the authors of the files in this folder? Voor je eigen mappen en de startbestanden van de cursus kies je Yes.

Een agent kan ook buiten die map werken als jij dat toelaat. Doe dat alleen als je weet waarom.

5Hou je verbruik in het oog

Chatten en werken met een agent kost AI credits. Elk plan heeft een tegoed per maand. Hoeveel een vraag kost, hangt af van het model en van hoeveel tokens er verwerkt worden. De suggesties die verschijnen terwijl je typt (code completions) kosten geen AI credits.

Klik op het Copilot-icoon in de Status Bar (4).

Je ziet hoeveel procent van je tegoed op is, en op welke datum het opnieuw begint. Dat is de eerste dag van elke maand.

Verdeel je tegoed over de maand. Je hebt Copilot nodig in elke les en voor de oefeningen. Is je tegoed op, dan werkt de chat niet meer tot de volgende maand. Gebruik dus niet alles in één keer.

Zo verbruik je minder

  • Begin een nieuw gesprek voor een nieuwe taak. In een lang gesprek gaat de hele geschiedenis telkens opnieuw mee.
  • Schrijf één duidelijke prompt in plaats van vijf vage. Dat leer je in module 2.
  • Typ /compact in een lang gesprek. De agent harness vat het gesprek dan samen, zodat de context kleiner wordt.
  • Ga met je muis op een antwoord staan. Je ziet hoeveel credits die vraag kostte.

6Kies een model

In het invoerveld van de chat staat de model picker (B in de schets hieronder). Daar staat standaard Auto: Copilot kiest dan zelf een model voor elke vraag.

  • Met Copilot Student of Copilot Free is Auto de enige keuze. Je hoeft dus niets in te stellen.
  • Met een betaald plan (bijvoorbeeld Copilot Pro) kan je zelf een model kiezen. Ga met je muis op een model staan: je ziet een label Low, Medium of High voor de kost. Een sterker model geeft vaak betere output, maar je tegoed is sneller op. Een voorbeeld van een snel en goedkoop model is Gemini 3.8 Flash: niet het sterkste, wel veel waarde voor weinig credits. Kijk altijd naar het label, want modellen en prijzen veranderen.

7Permissions: wat mag de agent zonder te vragen?

Een agent voert acties uit: een bestand aanpassen, een commando in de terminal starten, een webpagina ophalen. Met de permissions picker (C) kies je voor welke acties de agent eerst jouw toestemming vraagt.

NiveauWat gebeurt er?Voor wie?
Manual permissionsDe standaard. Je keurt zelf elke actie goed die niet vooraf is toegelaten, bijvoorbeeld een commando in de terminal. Veilige acties, zoals een bestand lezen, gaan vanzelf.Het veiligst. Je moet wel vaak klikken.
Assisted permissionsEen model beoordeelt elke actie. Acties met weinig risico gaan vanzelf. Bij de andere vraagt de agent jouw toestemming.Een goede middenweg. Let op: dat model kan zich vergissen.
Allow allDe agent voert alles uit zonder te vragen. Dat geldt ook voor Autopilot.Niet in deze cursus.

Ons advies: ga nooit verder dan Assisted permissions. Met Allow all kan een agent alles doen zonder te vragen. Ook je bestanden of een database wissen. Het is jouw computer en jouw verantwoordelijkheid. Kies je er toch voor, dan is dat op eigen risico.

Welk niveau je ook kiest: lees wat je goedkeurt. Klik niet blind op Allow.

8Instructiebestanden: vaste afspraken voor de agent

Een instructiebestand is een tekstbestand in je project met vaste afspraken. De agent harness leest het vanzelf bij elk gesprek. Je hoeft die afspraken dan niet in elke prompt te herhalen. Voor GitHub Copilot is dat AGENTS.md in de hoofdmap van je project, of .github/copilot-instructions.md.

# AGENTS.md
Dit project is een webshop in JavaScript (Node.js).

- Schrijf code en commentaar in het Engels.
- Bedragen zijn altijd in eurocent, als gehele getallen.
- Installeer geen nieuwe packages zonder het te vragen.
- Test je wijziging met: node check-korting.js

Je hebt dit nu nog niet nodig. Later in de cursus leer je hoe je een goed instructiebestand schrijft.

9Werk je liever met een andere agent harness?

Dat mag. Je kan bijvoorbeeld Codex of Claude Code gebruiken. Dat is jouw keuze. Hou rekening met het volgende:

  • Alle uitleg in de les en in de cursus is voor GitHub Copilot.
  • De basis is overal bijna dezelfde: een chat, permissions, een instructiebestand. Ook /compact bestaat in de meeste agent harnesses.
  • De namen verschillen. Claude Code leest bijvoorbeeld CLAUDE.md, Codex leest AGENTS.md. Ook de niveaus van de permissions heten anders.
  • Je zoekt die verschillen zelf op in de documentatie van jouw agent harness.

✓Checklist

  • VS Code is geïnstalleerd en up-to-date.
  • Ik ben in VS Code aangemeld met mijn GitHub-account.
  • Mijn studentenplan is aangevraagd of actief.
  • Ik kan de chat openen, en ik krijg een antwoord op een korte vraag.
  • Ik weet waar ik mijn verbruik en de resetdatum zie.
  • Ik open een map voor ik een prompt typ.
  • Mijn permissions staan op Manual of Assisted permissions.

Werkt er iets niet?

  • Ik zie geen chat. Kies Chat > Open Chat of druk Ctrl + Alt + I. Werk VS Code bij als het menu ontbreekt.
  • De chat antwoordt niet, of de lijst met modellen is leeg. Kijk of je aangemeld bent met het juiste GitHub-account. Meld je af en opnieuw aan via Accounts.
  • Mijn aanvraag is nog niet goedgekeurd. Start met Copilot Free en ga zuinig om met je tegoed.
  • Nog altijd vast? Vraag hulp bij het begin van de les.

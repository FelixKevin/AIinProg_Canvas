Oefeningen module 4

In deze opdracht maak je de oefeningen van module 4: Code begrijpen, reviewen en verbeteren. Je maakt ze tijdens de les. Volg je de les niet in het lokaal? Dan maak je ze zelfstandig: op de pagina met de oefeningen staat onder Zo doorloop je deze les in welke volgorde je leest en werkt. Je werkt in een invulbestand en levert dat bestand hier in.

Zo ga je te werk

  1. Download het invulbestand: oefeningen-module-4-invulbestand.docx.
  2. Download de startbestanden en pak de zip uit: startbestanden-module-4.zip. Je hebt ze nodig voor elke oefening van de kernreeks.
  3. Open de pagina Oefeningen module 4. Daar staan de volledige opgaven. Lees eerst het deel Voor je begint: daar staat welke map je voor welke oefening opent, hoe je het project start en hoe je de berekeningen controleert.
  4. Typ je antwoorden in de lichtblauwe vakken van het invulbestand. Verwijder geen titels of vragen.
  5. Bewaar je bestand als .docx of .pdf met de naam module4_voornaam_achternaam.
  6. Lever het bestand in via deze opdracht.

Wat maak je?

  • Kernreeks (verplicht): M1, E1, M2, M3 en M4, in die volgorde.
  • Extra-reeks (optioneel): X1 tot en met X12. Wil je meer oefenen, maak er dan zoveel als je wil.

In alle oefeningen van de kernreeks werk je met hetzelfde project: een 3D-scorebord dat je overneemt van een collega. Je hoeft het niet zelf te bouwen, en je hoeft niet elke regel te begrijpen. Je leert het kennen, je laat het reviewen, je verbetert het en je zoekt er een fout in, met een agent als hulp.

Wat zit er in de startbestanden?

  • scorebord: het project, voor M1, E1 en M2.
  • scorebord-verbeteren: hetzelfde project, voor M3.
  • scorebord-fout: hetzelfde project met één extra fout, voor M4.
  • scorebord-thuis: hetzelfde project, voor de extra-reeks.
  • rangschikking: één bestand met drie versies van een function, voor X12 in de extra-reeks.

Je krijgt het project meerdere keren. Zo begint elke oefening waarin de agent code verandert met een project dat nog niet veranderd is, en hoef je nooit iets ongedaan te maken.

Wat lever je in?

Je levert alleen het invulbestand in. Screenshots, code en output plak je in het invulbestand, op de plaats waar de oefening erom vraagt. Je mappen lever je niet in. Bewaar ze wel bij je portfolio.

Wat heb je nodig?

  • Een agent harness, zoals GitHub Copilot in Visual Studio Code, voor elke oefening waarin je een prompt verstuurt. Is dat nog niet in orde? Volg dan de startgids: startgids-vscode-copilot.pdf.
  • Een browser, zoals Chrome, Edge of Firefox, en een internetverbinding.
  • Node.js, voor alle oefeningen. Op de pagina met de oefeningen staat hoe je controleert of het geïnstalleerd is.

Elke prompt kost AI credits, en je tegoed per maand is beperkt. Daarom zegt elke oefening hoeveel prompts je hoogstens stuurt. Hou je daaraan. Noteer bij elke oefening waarin je een prompt verstuurt welke agent harness en welk model je gebruikte.

Je prompts, je antwoorden en je conclusies schrijf je zelf. Je moet alles wat je inlevert kunnen uitleggen.

Waarom lever je dit in?

Je ingevulde oefeningen zijn een deel van je portfolio, en ze tellen mee voor je eindcijfer. In de examenperiode van januari verdedig je je portfolio mondeling. Werk dus zorgvuldig: je docent kan je vragen om alles wat je hier schrijft uit te leggen.
